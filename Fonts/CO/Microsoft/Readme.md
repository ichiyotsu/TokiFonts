## Mircrosoft Yahei

Microsoft YaHei（微软雅黑）是微软公司委托方正电子（Founder）于 2004 年左右研发并于 2006 年随 Windows Vista 及 Office 2007 正式发布的无衬线现代黑体系统字体系列，正式取代了此前在 Windows XP 中饱受诟变的低清点阵字体新宋体/宋体，目前是 Windows 生态中最核心的默认简体中文系统视觉字体。

**设计变体**

`YaHei` 简体中文标准变体，针对屏幕呈现进行了 `ClearType` 渲染技术的深度像素级着色优化 `UI` 界面变体，专为操作系统 UI 按钮、菜单、对话框紧凑排版设计，微调了字距与西文字符比例

**字重**丨共 3 种丨目前提供 2 个文件（仅 Yahei 常规 & 粗体）

Light（细）、Regular（常规）、Bold（粗体）。
